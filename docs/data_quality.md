# Data quality: Berkeley Lab Queued Up (data through end-2025)

Generated by `python -m queue_risk.quality`; do not edit by hand.

Scope: 29,848 clean-energy projects (solar, wind, storage) entering 2005 or later, unless a row says whole file.

| Issue | Rows | Effect | What we do |
|---|---|---|---|
| Repeated entity|q_id (whole file) | 135 | Double-counted projects | Keep the more complete row of each pair |

| Operation/withdrawal/IA date after the file's as-of date | 52 | Planned dates read as observed | Set to missing |
| Request modifies an existing plant (Surplus/Replacement/Upgrade) | 97 | Not a new project | Excluded |
| Operation date before queue date | 18 | Timing unusable | Excluded |
| Withdrawn project with an operation date | 222 | Would be labeled built by a date-only rule | Status decides: not built |
| Active/suspended project with an operation date | 133 | Same | Status decides: not built |
| Operational project with a withdrawal date | 6 | Contradictory | Status decides: built |
| Operational, no operation date (all regions) | 623 | 5-year label unknown | Outcome scoped to six date-reporting operators |

| Withdrawn, no withdrawal date | 6,642 | Track-record features undercount past withdrawals | Documented; lag features treat as unknown |
| IA executed, no IA date (not yet operational) | 2,303 | Post-IA build rate rests on a subset | Post-IA rates reported as a range |
